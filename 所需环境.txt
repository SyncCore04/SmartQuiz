需要安装的软件

1. Python 3.8 或更高版本
下载地址：https://www.python.org/downloads/
安装时务必勾选 “Add Python to PATH”
安装后验证：命令行执行 python --version 和 pip --version

2. Node.js（LTS 版本）
下载地址：https://nodejs.org/
安装后验证：命令行执行 node -v 和 npm -v

3. 微信开发者工具
下载地址：微信官方文档搜索“微信开发者工具下载”，选稳定版
安装后打开，用于导入和运行小程序

可选：Git、Postman/Apifox、浏览器

不需要安装：MySQL、Tomcat、JDK、Redis、Nginx
